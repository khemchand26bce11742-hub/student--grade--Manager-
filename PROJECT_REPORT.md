# Project Report
## Smart Expense Tracker

### 1. Introduction
Smart Expense Tracker is a command-line Python application designed to manage personal income and expenses.

### 2. Objective
The main objective is to provide a simple program for recording transactions and viewing basic financial information.

### 3. Features
- Add income and expenses
- View transactions
- Calculate financial summary
- Search transactions by category
- Menu-driven interface

### 4. Technologies Used
- Python 3
- Functions
- Lists and dictionaries
- Loops
- Conditional statements
- File handling

### 5. Working
The application displays a menu to the user. The user can select an option to add a transaction, view transactions, check the financial summary, or search by category.

### 6. Execution
The project can be executed from a terminal using:

python main.py

### 7. Conclusion
This project demonstrates the use of fundamental Python programming concepts to create a practical command-line application for expense management.
